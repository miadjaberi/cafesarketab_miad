راهنمای تست روی موبایل دیگر / گیت‌هاب / سوپابیس
================================================

۱) فرستادن ZIP برای تست روی موبایل دیگر
-------------------------------------
روش ساده:
• فایل Kafe-miad-V22.9-RC1-FINAL.zip را با تلگرام/واتساپ/بلوتوث برای گوشی دوم بفرستید.
• روی گوشی دوم ZIP را باز کنید (استخراج).
• پوشه را در Files نگه دارید.
• توجه: باز کردن مستقیم از فایل (file://) برای ورود مدیر، OTP و سرور محدودیت دارد.
• برای تست واقعی: همین فایل‌ها را روی هاست HTTPS بگذارید و فقط «لینک» را برای گوشی دوم بفرستید.

بهترین حالت تست:
  لینک HTTPS  ←  در تلگرام برای گوشی دیگر بفرستید.

۲) گیت‌هاب (لینک عمومی)
-----------------------
الف) ساخت مخزن:
  1. github.com → New repository (مثلاً kafe-miad)
  2. محتویات ZIP را در ریشه مخزن آپلود کنید (index.html باید در ریشه باشد)
  3. Settings → Pages → Source: Deploy from branch → Branch: main → Save
  4. بعد از ۱–۲ دقیقه لینک شبیه:
     https://USERNAME.github.io/kafe-miad/

ب) با Git (اختیاری):
  git init
  git add .
  git commit -m "V22.9-RC1"
  git remote add origin https://github.com/USERNAME/kafe-miad.git
  git push -u origin main
  سپس GitHub Pages را مثل بالا روشن کنید.

۳) سوپابیس (داده و سرور — نه جایگزین هاست ظاهر)
-----------------------------------------------
سوپابیس جای «ظاهر اپ» نیست؛ برای کاربر، سفارش، اشتراک، پیام و OTP است.

کارهایی که باید در پروژه Supabase شما باشد:
  • جداول: profiles, products, orders, subscriptions, messages, conversations, app_settings, ...
  • Auth فعال
  • Edge Function: admin-telegram-otp (از قبل برای مدیر)
  • اختیاری: channel-membership (اگر قفل سخت کانال با ربات بخواهید)
  • در index.html / تنظیمات اپ همان URL و anon key پروژه شما

آپلود فایل‌های استاتیک روی خود سوپابیس معمولاً لازم نیست.
مسیر پیشنهادی:
  ظاهر اپ → GitHub Pages یا هاست دیگر (HTTPS)
  داده و ورود → همان پروژه Supabase

بعد از آپلود:
  1. لینک را روی موبایل باز کنید
  2. یک‌بار کش مرورگر را خالی کنید اگر نسخه کهنه دیدید
  3. تست: ثبت‌نام، مودال، خرید، پیام، ورود مدیر

پاک‌سازی داده آزمایشی روی سرور:
  از پنل Supabase Table Editor ردیف‌های تست orders / messages / subscription_requests را حذف کنید.
  (کد ZIP فقط حافظه محلی مرورگر را در اولین باز شدن V22.9-RC1 تمیز می‌کند)
